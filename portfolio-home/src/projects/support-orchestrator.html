A support bot where a router agent reads each message and decides whether a knowledge-base agent answers it or a human takes it.

Key decision
Upset customers and exception requests go to a person, not the bot.
Why
That's where a fluent wrong answer does the most damage: granting a refund the policy doesn't allow, or arguing with someone who is already angry. The escalation agent doesn't reply to the customer. It writes a two-sentence summary with an urgency label, so the person picking it up starts with context.
Gave up
Some tickets the bot might have handled now go to the human team.
